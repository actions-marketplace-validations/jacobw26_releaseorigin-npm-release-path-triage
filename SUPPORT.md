# Support

Use GitHub Issues for an ordinary usage question or bug with the smallest
public reproduction possible.
Include the Action version or immutable commit SHA, the exact public npm
package name, the returned classification/reason, and public source links.

Do not post a credential, token value, private repository or workflow,
maintainer contact detail, customer data, or security-sensitive reproduction.
Use the private process in `SECURITY.md` for a suspected vulnerability.

ReleaseOrigin is bounded public-workflow triage, not a security scanner,
compliance opinion, provenance verification, or guarantee about a release.
